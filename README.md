# Prabhakar J — Personal Portfolio

A responsive React + Vite portfolio starter with a charcoal / champagne-gold visual system, Framer Motion reveals, and a React Three Fiber 3D contact orb.

## Requirements
- Node.js 18+
- npm

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Before publishing
1. Add your final resume PDF as `public/resume.pdf` (the Resume buttons currently point to this path).
2. LinkedIn and GitHub profile links are configured in `src/App.jsx` (GitHub: `https://github.com/light337-hub`).
3. Replace or add real project screenshots in `src/components/ProjectVisual.jsx`.
4. Complete the AURA case study with confirmed screenshots, architecture and measured results. The Projects section also links to your GitHub profile so visitors can browse your public repositories.
5. Review the wording of internship dates and all skills before publishing.
